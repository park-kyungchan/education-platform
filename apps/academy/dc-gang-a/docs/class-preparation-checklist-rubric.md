# Class preparation checklist rubric

Owner: Academy classroom operations. Current teacher additions: 2026-10-28.
This is a qualitative inspection checklist, not an automatic grading scale,
student record, source-save permission or scheduled notification.

## Evidence and scope

Organize each check by business date, lesson part, student, exact book edition,
major unit, minor unit, activity and occurrence. Keep assigned work, student
performance, source answer entry, source scoring, corrections and teacher review
separate. An absent source row is unknown. Only an actual assigned obligation
with evidence of nonperformance is incomplete homework.

## Required notebook checks

| Material | Applicability | Required checks |
| --- | --- | --- |
| Gauss solving notebook | The student's Gauss textbook work | Confirm the separate Gauss notebook, the assigned unit/section/item range, written solution process, student completion and teacher inspection. |
| Supplementary-book solving notebook | The student's independently identified supplementary book | Confirm a separate notebook for that book and check its assigned range, written solution process, student completion and teacher inspection. Do not merge it with the Gauss notebook or infer the book title. |
| Gauss study-notes notebook | Gauss preparation only | Writing is mandatory during preparation. Check the exact unit, whether the notes were written, and whether the teacher inspected them. Video upload, watching, notes, concept blank tests and understanding are distinct observations. |

Do not automatically require a study-notes notebook for supplementary books.
Do not add a numeric notebook score, page quota, presentation standard or
automatic homework-grade conversion without a teacher decision.

## Homework and lesson review

- Establish the actual assigned stages first. If solving alone was assigned,
  absent at-home grading or correction is not incomplete homework. Record
  corrections completed in class in that lesson's progress.
- Check Gauss and supplementary-book solving notebooks separately. Record
  student writing and teacher inspection separately; request correction or
  supplementation only for a specifically observed issue.
- Check Gauss preparation notes independently of the preparation video and its
  teacher review. Unknown notebook status remains unknown even when a video or
  concept blank test is complete.
- Keep concept blank tests, original-error clinics, similar-problem clinics and
  DailyTest basic/advanced rounds as separate checks for every relevant unit.
- Apply only that student's teacher-confirmed assessment target. A score does
  not establish corrections or teacher-final completion.
- Carry forward only active assignments and attributable follow-up checks.
  Preserve teacher completion, cancellations and replacements. Use an actual
  deadline; a Friday follow-up check does not create a Friday homework deadline.

## Checklist presentation

For each activity show the assigned scope, observed student work, teacher check,
source-entry/scoring evidence when relevant, and the next check. Use explicit
states such as unknown, assigned, student work complete, teacher checked,
supplement needed or teacher-final complete. These states are observations,
not an ordinal scale or an inferred native code.

## Textbook section result reports

Teacher preference confirmed 2026-10-28: when reporting
`academy_textbook_section_results`, use the following default presentation.

- Write the report in Korean. Start with the reporting business date and
  requested student/class scope. Keep students in the requested order, with
  numbered student entries and numbered book-specific subsections.
- Identify the exact book, term, series and edition when established. Preserve
  the source unit code and name. Never combine similarly named units from
  different books or editions.
- State the number of observed records and actual selection coverage. Show
  `correctCount/itemCount (source score)` without recalculating the source score.
  Label the returned source month/day as the source display date, not the exact
  grading time or today's performance date.
- For several units in one book, prefer a matrix with units as rows and actual
  section labels as columns, plus source dates. For a smaller selection, use
  rows of unit/section, correct/item counts, source score and source date.
- Include the original worksheet's incorrect item ordinals when they are useful
  to the teacher. They are not clinic item ordinals. Parent-facing text continues
  to follow the separate DailyRecord policy's count-only clinic presentation.
- A dash means no record observed in the qualified selection. It never means
  the section does not exist, was not assigned or was not performed. Existing
  scored records do not establish a complete printed section inventory.
- Keep `실력쌓기`, `실력다지기` and `실력올리기` as distinct labels. Do not copy a
  section inventory from another textbook or treat source status columns as
  printed sections.
- End each student's entry with the relevant current checks. Preserve the
  teacher's scoped correction/completion decisions beside historical original
  scores; do not reopen completed work because an old score is low.
- State whether the action was a read or an actual save. The report format grants
  no source-write, grading, printing or parent-send authority.

Keep dated student examples, scores, decisions and reminders in the private
work context. Include requested follow-ups in the next dated checklist; do not
claim that a timed notification was scheduled unless it actually was.
