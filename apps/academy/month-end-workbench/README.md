# Month-end research workbench backend

A source-backed, read-only teacher research and question-review application. Browser and HTTP server run the same pure `createApplication` logic. Research originals belong to `math-research-module`; Academy hierarchy, type labels (`pat_no`) and question revisions (`lecture_key`) retain their source ownership and distinct namespaces. Shared upper meaning remains immutable `@palantirkc/ontology`0.2.0; this app defines no common Artifact validator or central identity registry.

From this package directory:

```sh
bun install --frozen-lockfile --ignore-scripts
bun run check
bun run source:verify -- /absolute/path/to/pinned/math-research-module
bun start
```

Default loopback URL `http://127.0.0.1:4327`; override with bounded `MONTH_END_PORT`. Build the sibling `month-end-web` package first to serve its `dist/index.html`. `MONTH_END_SOURCE_MODE=synthetic bun start` enables clearly marked engineering questions. Default Academy mode is unavailable; original research remains available. An operator may select `MONTH_END_SOURCE_MODE=native-readonly` and an explicit private `MONTH_END_SOURCE_CONFIG` path for the server-only pinned integration adapter. Configuration pins executable, complete compiled MCP bundle and native owner bridge configuration bytes. Credentials stay with the native owner. No implicit config discovery, global settings, SQL, deployment or source write is performed.

The deterministic importer verifies exact revision `07edb2dea2e5997aea4318f0fa2efa21dde633df` and all238 original tracked repository blobs, including109 archive files. It uses the source-owned identity validator plus independent application admission guards. `data/source-lock.json` is an explicit reviewed pin, never automatically regenerated. `data/research-projection.json` retains105 grade3 types,46 scoped later-grade connections,151 basic examples plus19 variants,151 original research designs and1216 original microsteps. It includes curated PR3 requirement records, source metadata and the synthetic identity pilot; original conversation bodies, learner records, credentials and publisher PDFs are excluded. All accepted source pointers carry exact path/revision/hash. A byte digest proves integrity, not currentness or mathematical correctness.

The four-level core hierarchy preserves sibling navigation; upper connections retain their own source structure rather than invented levels. Containment, source content prerequisites/connections, type membership, capability hypotheses and literature evidence are distinct links. Research designs remain unvalidated hypotheses. The24×3 worked case is an assistant illustration; a correct72 alone cannot identify understanding. `HC11-d1-T02` retains a visible proposed-not-applied warning: under its exact three-point conditions L is the unique center. Originals and correction proposal status remain unchanged.

Study completion is an explicit teacher report for exact type IDs/research revision/edition/unit. A changed scope invalidates completion. Every find/review request binds the current report, intent axes and exact source observation context. Teacher-declared edition/unit and native-observed metadata remain separate: unknown source metadata permits explicitly provisional reads with a Korean warning and stays null; known conflicting metadata holds comparison. Equal strings alone establish no edition identity or mathematical suitability. Lexical retrieval has unknown structure/reasoning/representation/conditions/errors/transfer evidence; it cannot become semantic probability or final ranking. Only labels returned for the selected source context can be reviewed. Question pages preserve membership and their separate observation revisions. Qualified preview references remain links; this backend never fetches source images.

The HTTP boundary uses exact loopback Host/Origin, bounded session/CSRF context, exact routes/keys and bounded bodies. Sessions expire after30minutes and share one immutable research projection while retaining isolated ephemeral study state. After inspecting a question page, the teacher can create an ephemeral six-axis Research↔Academy alignment memo. It derives source/research evidence from admitted exact question revisions, retains teacher attribution and proposal-only status, and becomes historical when study/intent/source changes. Supported/conflicting axes require a note and inspected question; caller hashes or acceptance claims are refused. Question digests identify returned validated projections, not publisher originals or full acquired content. At most40 proposals and100 inspected question projections (2MiB total) are retained per session. No persistence, final item membership, generation, printing or send action exists. Source availability, byte integrity, observed revision, coverage, content acquisition, interpretation, teacher acceptance and production completion remain separate.

Verification is local TypeScript/Bun, synthetic domain/HTTP/official-SDK integration behavior and pinned source projection reproduction. It does not establish full151-example mathematical or pedagogical audit, learning effects, real teacher completion, native currentness, mathematical-core R4 acceptance or production readiness. Root owns separately authorized native read probes and delivery.
