# Reusable Academy Jev cost reduction work

This local Work designs a common capability and uses the October grade3 assessment and DailyRecord as its first cases. It does not create a new agent runtime or claim global Work registration.

The native pilot made three version-pinned Jev calls through the existing VPS Vercel AI Gateway owner. Gateway-reported cost was US$0.001486842 for 35401 input and 1254 output tokens; measured request time was 3582ms. Document checks matched 5/5 gold answers and teacher-fact checks 10/10. Image mathematical choices matched 3/4; only 1/4 also met the pilot confidence threshold. The remaining image calls stopped before submission. No comparative total-cost saving has yet been measured.

Code should perform identity, membership, quota, page-count and title checks. Jev should select bounded classification labels, prepared candidate reason codes, source-bound record clauses and image findings. Code renders record drafts from templates; Codex handles new unconstrained wording. Native Codex should handle uncertainty, contradictions, mathematical derivation and unsupported source protocols. Existing native Academy clients retain authentication, approved writes and independent readback; the official program retains PDF typesetting.

For research, deterministic code selects cached document paths, Scrapling fetches missing sections, and Jev selects relevance or support labels through Choice, Score and Noul. These primitives return decisions, not arbitrary generated prose. A model decision does not fetch a URL. For PDFs, code first compares original embedded pixels and layout; only changed content or unresolved cases need renewed model review. Reused evidence must remain marked as reused.

Each candidate explanation must bind its original item, source solution, research microsteps and DATA/LOGIC/ACTION/GOVERNANCE units. Explain which mathematical structure matches, which solving steps are elicited, what is absent, and why the item is preferred over its alternative. Metadata similarity alone is insufficient.

The proposed routing policy requires separate local calibration for text facts, layout and mathematics. The current low-confidence wrong geometry answer supports escalation; four examples cannot establish a universal confidence threshold. CISM remains a proposed next case until its actual report period and source inputs are selected.

See [work.json](work.json) for actual observations, user decisions, routing proposals and remaining validation. No key, raw student record, PDF bytes or private runtime store is included.

A major redesign target is operational overhead: repeated authentication, repeated source loading, duplicate compilation and per-query helper construction. A maintained native MCP adapter should own the qualified protocol and reuse its existing authenticated connection. Jev then receives only bounded task facts, while code performs transport and accounting. Measure the entire flow before claiming savings; three fast model calls do not measure the surrounding engineering time.
