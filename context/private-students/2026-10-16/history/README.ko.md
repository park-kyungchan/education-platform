# 과거 학습 근거 보존 패키지

이 패키지는 이미 로컬에 보존된 다섯 학생의 교육 자료를 선별한 것입니다. 새로운 서버 조회를 하지 않았으며 전체 재학 이력 또는 현재 시점의 상태가 모두 검증되었다는 뜻이 아닙니다.

## 구조와 확인 결과
- manifest.json: 출처 77개, 원본 SHA-256, 저장본 SHA-256, 77개 객체 경로, 원문에 명시된 시각, 출처 종류와 한계.
- objects/: 선별한 교육 근거 본문. 원본 바이트 보존이 기본이며, 네 학생 확인 메모만 교육 내용과 무관한 실행 경계 설명을 제외했습니다. 원본 해시와 변환 이유가 남아 있습니다.
- actual-catalog-sections.json: 과거 636행 가운데 실제 catalog_section 277행. 실제 카탈로그에 있다는 의미이지 과제 부여나 학생 완료의 증거가 아닙니다.
- synthetic-slots-exclusion.json: verification_slot 359행의 제외 원장. 합성 검토 칸을 실제 소단원이나 학생 미완료 과제로 사용하지 않습니다.
- validation.json: 원본 및 저장본 해시, 과거 참조 7개 실제 본문 연결, 277/359 분리, 금지 텍스트 패턴 검사 결과.

## 포함 범위
- 역사 원본 ref_0_data.json부터 ref_22_data.json까지 23개.
- 다섯 학생별 audit 원장 5개. 원장 내부의 기존 해석은 당시 상태로 보존하며 현재 판정으로 자동 채택하지 않습니다.
- 10월 14일의 저장된 공식 화면 관찰, 이루한·이현승 관찰/교사 보고 이벤트.
- 10월 16일 DailyRecord 조회 범위, 유지연 82행과 그중 강아 워크북 55행, 가우스 플러스 사용자 목차와 교사 판정.
- 박세은·이현승 섹션/근거 원장, 박세은 평가 종류 정정 및 10월 19일 숙제 수정 이력.
- 38개 및 40개 문항 답안 조회 결과. 정답 자료이며 학생의 채점 결과가 아닙니다.
- 상위 class-context의 historicalArtifactIndex 7개 모두 저장 객체로 연결됩니다.

## 충돌 해석 우선순위
1. 원본 서버 관찰과 사용자 직접 교사 보고를 각각 보존합니다. 서로 다른 증거 종류를 대체하지 않습니다.
2. 더 나중의 명시적 사용자 정정은 같은 범위의 기존 해석보다 우선합니다. 날짜 없는 데이터는 최신으로 취급하지 않습니다.
3. 유지연의 교재 풀이와 교재 내부 오답은 10월 16일 사용자 완료 판정입니다. 별도 오답클리닉·유사클리닉은 대기입니다. 55/82는 조회 행 수이지 완료 수가 아닙니다.
4. 박세은 9월 19일 90점은 서버 프린트 총괄평가, 10월 2일 일지 86점(14/16)은 교재 내부 총괄평가입니다. 서로 합치거나 완료 판정을 상속하지 않습니다.
5. 100점인 원응시에 오답이 없다는 사실은 유사클리닉 완료를 증명하지 않습니다.
6. 박세은 10월 19일 숙제는 최신 수정 p.53~59입니다. 과거 p.53~68은 변경 이력으로만 남깁니다.

## 비포함과 미확인
계정 자격증명, 브라우저 프로필, 내부 운영 메모, 코드 지침, 학원과 무관한 자료를 수집하지 않았습니다. 별도의 PDF 렌더링본·이미지·코드·실행 로그·중복 출력물은 이 근거 패키지에 추가하지 않았습니다. 원문에 조회 시각이 없으면 null이며 파일 수정 시각으로 대체하지 않았습니다. 이전 Space 본문과 그 첨부 수집은 별도 space 패키지에서 다룹니다. 사용자의 전체 과거 자료를 빠짐없이 모두 발견했다는 보장은 하지 않습니다.
