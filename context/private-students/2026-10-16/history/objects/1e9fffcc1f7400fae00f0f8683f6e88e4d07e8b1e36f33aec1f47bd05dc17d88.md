## 누락·명칭 차이 확인

검증된 서버의 박세은 다빈치 1SJ2 화면과 기존 21개 문제 섹션 목록을 대조했다.

- **개념정복, 읽기와 쓰기, 개념복습**: 서버에는 있으나 기존 문제 섹션 목록에 없었다. 교재 전체 추적용 목록에 추가했다. 이번 숙제에 추가한 것은 아니다.
- 실력다지기·실력올리기·필수예제: 기존 목록과 서버 이름이 일치한다.
- ‘읽기+쓰기’는 서버 ‘읽기와 쓰기’의 해당 교재 표시 별칭으로, ‘개념 복습’은 ‘개념복습’의 공백 차이로 기록했다.
- ‘대단원 총괄평가’와 서버 ‘대단원총괄평가’는 공백 차이다. 기존 ‘단원평가’ 노드와는 대응 후보를 남기고, 교재 내 평가와 별도 서버 프린트 평가의 응시·완료를 합치지 않는다.
- **‘만점도전 생각근육 키우기’는 사용자 원문 그대로 유지**했다. 서버 ‘만점도전’과 기존 ‘생각근육키우기’의 관계는 아직 확정하지 않았다. 별도 두 과제로 늘리거나 기존 응시·완료를 합치지 않았다.
- 평가클리닉(두 위치)·오답재학습은 진행 상태 열이다. 새 교재 섹션으로 만들지 않았다.
