## 핵심 연결 구조
학생 → 반편성/실제 수업일 → 등록·보관 교재 → 판본 → 대단원 → 소단원/총괄평가 → 섹션 → 학습활동 → 배정/회차/응시 → 교사 확인 → DailyRecord 초안/저장 → 학부모 전달.

각 화살표는 확인된 근거가 있어야 연결한다. 파일에 기록됐다는 이유만으로 학원사이트 입력·학부모 발송·프린트 전달을 완료로 바꾸지 않는다.

## 적용 원칙
- 최신 명시적 사용자 정정이 같은 대상의 과거 상태보다 우선한다. 과거 사건은 삭제하지 않고 당시 상태로 보존.
- 미확인은 미수행이 아니다. 완료 예정은 완료가 아니다. 교재명 연결이 모호해도 명시적으로 확인된 완료 사실은 유지.
- 날짜·회차·교재가 다른 같은 이름의 과제는 합치지 않는다. 전체 목차는 배정 숙제의 분모가 아니다.
- 이 묶음은 확보한 근거의 통합 인계자료이며 전 기간·전 출력물의 완전한 전수감사라고 주장하지 않는다.
- 학습정보가 포함된 비공개 자료다. 새 수신자·플랫폼으로 전송하거나 공개하려면 사용자의 대상·범위 승인을 확인한다.
- 학부모용 문장은 ‘진도/숙제/메모’로 따로 작성하고 ‘교사완료판정’ 같은 내부관리 용어를 쓰지 않는다.
