# 가우스·부교재 식별 및 학습판정 매핑 규칙

2026-10-21. 사용자 정정 반영. 서버 변경 없이 기록 해석·검토에 적용하는 규칙.

## 1. 식별 계층
1. 학생 → 교재 판본 → 실제 목차 경로 → 섹션 → 활동 → 과제/회차 → 응시 → 교사 판정.
2. 교재는 학교급/브랜드/학년/학기/시리즈/개정교육과정/판본/서버등록코드를 분리한다.
3. 실제 목차의 대단원/중단원/소단원을 보존한다. 서버 두 숫자 라벨만 보고 인쇄본 중단원 계층을 지우지 않는다.
4. 초등 가우스 ‘5-1-2’는 초5·1학기·시리즈2. ‘5-1-4-1’은 초5·1학기·대단원4·소단원1. 시리즈 번호가 아니다.
5. 인간 표시: ‘가우스 초5-1 · 시리즈2 | 4-1 크기가 같은 분수 알아보기’. 필요하면 교육과정 별칭 ‘초5-1-4-1’을 병기한다.
6. 단일 숫자열을 교재와 소단원 양쪽의 기본키로 사용하지 않는다. 초/중 표시를 생략하지 않는다.

## 2. 보수적인 기계 식별자
- book_edition_id: 확인된 서버 교재코드+버전, 또는 별도로 발급한 로컬 식별자. 미확인 필드를 0이나 추정값으로 채우지 않음.
- unit_id: book_edition_id + 실제 목차 node_id. node_id가 없으면 검증된 전체 목차 경로에 대한 로컬키를 사용하며 검증수준을 함께 기록.
- section_id: unit_id + 실제 섹션의 식별자. 필수예제/유형다지기/실력쌓기/실력다지기/실력올리기는 서로 교환하지 않음.
- activity_id: 예습영상, 교재풀이, 섹션채점입력, 개념백지, 원오답클리닉, 유사클리닉, DailyTest, 평가 등 구분.
- assessment_definition_id와 attempt_id는 별개. 기본/발전은 level, 재시험은 별도 attempt, 새 숙제는 별도 assignment_id.
- print_instance_id는 확인된 경우만. 반복 라벨을 새 프린트로 세거나 중복 삭제하지 않고 원문 기재와 실물 수량을 구분.
- teacher_decision에는 대상 활동/회차/판정일/근거/판정주체를 저장. 서버 자동평가와 분리.
- observed_at(조회시각), occurred_at(학습일), reported_at(보고시각), intended_at(계획일)은 별개.

## 3. 확정된 사례와 적용 경계
- 초5-1 시리즈2 대단원4 소단원1 = 크기가 같은 분수 알아보기. 소단원2 = 분수를 간단하게 나타내기.
- 박세은 Oct19 분수 DT4-1/4-2의 DailyRecord 교재5-2-2는 사용자 정정으로5-1-2. 기존 완료 사실 유지.
- 신지우의 초5-2 시리즈2 소수 곱셈4-1~4-7은 실제 별개 교재. 위 정정을 일괄 치환하지 않는다.
- 중1-2 가우스1-2-4는 마지막 시리즈이고1-2-1~1-2-4가 존재한다는 사용자10/14 설명을 보존한다. 이 사례를 모든 학년·학기 시리즈 수에 일반화하지 않는다.
- 중등 다빈치1-1은 사용자 설명상 시리즈 없음. 표지·서버에 없는 ‘1권’을 만들지 않는다. 초등 다빈치 표기와 별도 규칙으로 유지한다.
- 가우스플러스1-1은 가우스중1-1 시리즈2와 별개. 워크북 목록과의 연결은 근거수준을 명시.
- 시리즈 번호만으로 대단원 번호를 계산하는 규칙은 없다. 판본별 목차를 확인한다.

- 현재 신지우 초5-1 가우스 시리즈2는10/16 관찰한 공식 교재표시상 v1(1SAG). 이전 판본 미확인 메모는 이 교재에 대해 해소한다. 다른 학생·등록까지 자동 동일 판본으로 확정하지 않는다.

## 4. 총괄평가와 활동
- 대단원총괄평가는 사용자의 표시상 한 소단원으로 다룬다. 의미유형 chapter_assessment를 보존하며 임의 소단원0/99를 부여하지 않는다.
- 대단원 공유 평가를 모든 소단원에 중복 배정하지 않는다.
- Daily Restudy, 교재 평가클리닉 표시, 개념정복, 개념백지테스트, 예습영상은 서로 동의어가 아니다.
- 원점수100은 해당 원응시에 오답이 없다는 뜻일 수 있으나 별도 유사클리닉/DT를 완료 또는 면제로 만들지 않는다.
- 교재완료/종료인증평가 완료와 별도 종이 클리닉 최종 확인은 독립.
- ‘숙제해옴’, ‘풀이완료’, ‘채점완료’, ‘오답완료’, ‘교사최종확인’은 각각 보존한다. 사용자 명시적 범위 승인이 있을 때만 연결한다.

## 5. 사용자 오기 교정 절차
1. 원문을 보존한다.
2. 학교급·교재·단원명·과제일·판본·등록코드·인쇄헤더·사용자 정정을 비교한다.
3. 유일하게 결정되면 정규화값/원문값/근거/적용범위를 함께 기록하고 수정 내용을 알린다.
4. 둘 이상 가능한 경우 인터뷰한다. 비슷한 제목 또는 점수만으로 다른 교재로 이동하지 않는다.
5. 교재 연결만 불명확한 완료 항목은 완료를 유지한 연결대기다. 미완료로 되돌리지 않는다.
6. 기록 해석 교정은 학원서버 수정·DailyRecord 수정·학부모 전송 권한을 뜻하지 않는다.
