# 교재 특성·구조·학습 흐름 인계

기준일: 2026-10-21 한국시간. 이 문서는 사용자의 교재 운영 설명과 저장된 공식 화면·원문을 연결한 인계 자료다. 모든 판본·학생의 모든 페이지를 검증했다는 뜻이 아니다. 학생별 최신 상태와 구체적 교재 매핑은 이 팩의 학생 문서 및 매핑 문서를 함께 따른다.

## 1. 공통 식별 구조

학교급 → 교재 계열 → 학년 → 학기 → 시리즈/권(실제 존재할 때) → 판본 → 대단원 → 소단원 → 인쇄 섹션 → 회차·문항 → 활동·교사 확인 순서로 보존한다.

- 교재 표시명, 공식 코드, 판본, 원문 헤더를 별도로 보존한다. 표시명만으로 동일 교재를 확정하지 않는다.
- 가우스 5-1-2의 마지막 2는 시리즈이며, 소단원 좌표 5-1-4-1은 5학년 1학기 대단원4 소단원1이다. 둘을 같은 구조로 파싱하지 않는다.
- 10/21 사용자 확인: 가우스 5-1-2 대단원4 소단원1은 ‘크기가 같은 분수 알아보기’. 해당 분수 맥락의 DailyRecord ‘5-2-2’는 ‘5-1-2’ 오기였다는 정정을 반영한다. 별도로 실제 소수 곱셈 5학년2학기 기록까지 일괄 치환하지 않는다.
- 중등 다빈치 중1-1에는 시리즈가 없다는 사용자 정정을 유지한다. 중등 가우스·초등 교재의 권 구조를 복제하지 않는다.
- 사용자가 숫자나 계열을 잘못 말한 경우 제목·문항·교재 코드로 대조해 교정하되 근거가 부족하면 인터뷰한다. 원래 발언과 정정 이력을 남긴다.

## 2. 교재 계열별 역할과 차이

| 계열 | 확인된 역할·구조 | 주의 |
|---|---|---|
| 가우스 | 개념교재. 소단원 예습 후 학원에서 개념백지·클리닉·DT 등 진행 | 학교급별 섹션이 다름. 모든 활동을 자동 숙제로 만들지 않음 |
| 가우스플러스 | 부교재 계열. 유지연의 과거 ‘다빈치’ 표기가 가우스플러스로 정정됨 | 가우스 또는 다빈치와 병합 금지. 실제 섹션·권수는 판본 근거 필요 |
| 초등 다빈치 | 부교재. 관찰된 필수예제·실력다지기·실력올리기 등 | 중등 다빈치에 이름을 복제하지 않음 |
| 중등 다빈치 | 개념다잡기·회차별 실전 유형·서술형·대단원 평가 구조 관찰 | 앱 회차와 인쇄 섹션은 별도 층위 |
| 기타 부교재 | 사용자 설명에 오일러·파스칼 등이 있음 | 확인하지 않은 전체 목차나 학생 배정을 생성하지 않음 |

가우스플러스·다빈치·오일러·매그넘은 저장된 공통 정책상 개념노트/예습영상 대상 예외다. 이는 해당 활동 의무에 대한 예외이지 문제풀이·오답·교사 확인 면제가 아니다. 파스칼 등 다른 계열에 이 예외를 근거 없이 확대하지 않는다.

## 7. 학습 활동과 자료의 구분

### DailyTest와 Daily Restudy
- DT는 소단원별 별도 시험. 사용자 설명상 두 회분이며 중/중상 난도, 이후 기본/발전 등의 표기가 사용됐다. 실제 프린트 헤더를 보존하고 표기 간 대응을 임의 확정하지 않는다.
- 보통 예습한 소단원에 대해 학원에서 진행하되 신지우의 교재 전환 전 미실시 곱셈 DT는 숙제 예외로 배정됐다.
- Daily Restudy는 교재 섹션이며 DT와 동일하지 않다.

### 영상과 개념 활동
- 강의영상 시청, 학생 예습영상 업로드, 교사 검토, 개념노트 작성, 개념백지테스트는 독립 활동이다.
- ‘영상 완료’라는 모호한 발언은 어느 활동인지 확인한다. 업로드/검토대기/교사 확인을 구분한다.
- 다빈치에 영상이 존재한다고 예습영상 의무를 생성하지 않는다.
- 오래된 영상 목록이 사라졌다고 기존 교사 완료를 취소하지 않는다. 약 2주 보존이라는 과거 관찰은 시스템 TTL 확정 사실이 아니다.
- ‘오늘 처리 예정’은 처리 완료가 아니다.

### 클리닉과 프린트
- 오답클리닉과 유사클리닉은 각각 별도 자료·활동·최종 확인을 가진다.
- 생성 → PDF 확보 → 출력 → 배부 → 학생 풀이 → 채점 → 오답 수정 → 교사 확인은 다른 사건이다.
- 유사클리닉은 재생성 시 문항 배열이 바뀔 수 있다. 이미 인쇄한 종이는 당시 PDF·문항라벨에 연결하고 새 생성 배열로 대체하지 않는다.
- 같은 제목 반복은 동일 프린트라는 증거도 여러 장이라는 증거도 아니다. 문항라벨·생성 회차·기존 인쇄본 식별을 보존한다.
- 100점인 정확한 원응시 범위는 기본적으로 클리닉을 출력하지 않는 사용자 기준이 있다. 별도 요청은 예외. 점수만으로 교사 확인이나 별도 프린트 완료를 자동 생성하지 않는다.

## 8. 판정과 집계 원칙

- 대단원총괄평가를 소단원급 독립 항목으로 순서대로 출력하되 실제 교재 부모 대단원과 연결한다. 교재 내 평가와 출력 평가를 합치지 않는다.
- 학생 풀이 완료, 서버 채점 입력, 오답 수정, 교사 최종 확인을 각각 저장한다.
- 교사가 특정 완료 범위를 확정하면 교재 연결이 모호하다는 이유만으로 미완료로 되돌리지 않는다. 완료 사실과 연결 미확인을 함께 보존한다.
- 과거 완료 후 새 과제 회차는 별개다. 교사의 명시적 재검토·수정 요구가 없으면 새 조회 때문에 이전 완료를 재개하지 않는다.
- 상태는 미배정/미조회/근거 부족/진행/학생 완료 보고/오답 중/교사 최종 확인/제외/일시중지/해당 없음 등을 구분한다.
- 목차에 존재하는 모든 항목을 미수행이나 알림 대상으로 만들지 않는다.
