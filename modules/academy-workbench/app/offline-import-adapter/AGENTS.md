# Offline adapter boundaries
Use synthetic data in implementation tests. Real inputs/outputs belong only in a new separate private artifact, never fixtures, static assets or an unauthenticated preview. Keep the frozen runtime unchanged. Do not write any database or authentication setting, start a server, query an external source or create credentials. Preserve raw source bytes, scoped identity, independent clocks, correction relations and print snapshot semantics. Schema/hash checks are not factual verification or permission to operationalize student decisions. Actual output uploads require the already authorized private destination and independent review. Never silently discard unresolved source fields to make a display projection pass.
