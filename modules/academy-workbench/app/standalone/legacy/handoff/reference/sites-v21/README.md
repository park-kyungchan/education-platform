# Selected v21 source reference

This is an intentionally incomplete source tree. UI/domain/contracts are retained where vetted; selected tests use fictional fixtures. Private/generated modules, original configs, source captures and build scripts are excluded. Existing package.json scripts therefore must not be advertised as runnable here. Use the top-level static preview instead.

Any file listed as sanitized_reference in validation/source-hashes.json may differ by removal/replacement of provenance or account-identifying literals, generalized capture-count schema fields, a renamed historical-count field, or caller-supplied reminder configuration. See validation/omissions.json for the exact transformation categories. Such placeholders are not a real identity binding or authority proof. Unchanged hash pins may point to omitted private or missing source bytes and cannot satisfy a runtime gate without separately acquired authorized data.

Missing imports are documented in validation/dependency-gaps.json. They are migration work, not permission to restore private data into Git. Source schemas and field names that can hold sensitive values are retained without those values.
