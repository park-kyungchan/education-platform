# 교사 HITL 확정 도메인 계약

핵심 완료 판정 계약은 인터뷰 1–12로 확정했고, 영상 상세 검토 기준만 후속으로 유보한다. 기록, 관찰, 인간의 판단, 실행을 나누며 기존 교사 완료 사실을 새 점수나 빈 LMS 필드로 철회하지 않는다. 이 파일들은 외부 쓰기·인쇄·학생 평가 권한을 부여하지 않는다.

## 확인된 흐름

학생 답안 입력 관찰 → 교사 원천 확인 → PDF 생성 → 실제 출력 → 배부 → 학생 풀이 → 교사 1차 채점 → 오답 보완 → 교사 최종 검토. LMS 기록 대조는 별도 후속 축이다. 각 단계는 unknown/명시적 미완료/부분/보고됨/관찰됨/해당없음을 구분한다.

원응시와 출력한 PDF/종이의 고정 문항 구성은 서로 다른 식별자다. 학생 앱 재입력 시나리오는 구현 범위에서 제외한다. 하나의 원응시에서 오답클리닉과 유사클리닉을 별도 경로로 추적한다. 재생성으로 다른 문제가 생겨도 이미 배부한 문제지를 바꾸지 않는다. 정확한 식별자가 없으면 후보 관계로만 남긴다.

## 2026-10-14 17:18 확정한 응답

- 단순 보고 전달이나 화면 열람은 교사의 확인 완료가 아니다. 교사 확인은 명확한 학생·섹션 범위에만 적용한다.
- 예습 원응시 100점의 오답클리닉은 대상 없음이다. 이는 전체 학습 완료나 유사클리닉 면제를 뜻하지 않는다.
- 완료 판정 전 유사클리닉을 출력했는지 항상 질문한다. 필요 여부는 매번 교사가 정한다.
- 허위 수행 의심 또는 이해 부족 등은 교사가 제기한 경우 별도 검토 맥락으로 기록한다. 점수만으로 학생을 의심하거나 거짓이라고 단정하지 않는다.

## 적용 경계

policy.ts의 projectClinicGate는 오답·유사클리닉 쌍에만 적용하는 명시적 교사 근거 투영이다. DailyTest·영상·개념백지·마인드맵에 이 점수/출력 전제를 적용하지 않는다. 타입과 런타임 route 검증으로 오용을 거절한다. 임의 교사 판단이나 서버 쓰기를 수행하지 않는다.
