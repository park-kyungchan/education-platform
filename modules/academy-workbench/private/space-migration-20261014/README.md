# 학원 실무 Space 보존본

이 보존본은 강의하는아이들 학원 실무 Page와 17개 하위 Page, 직접 연결된 126개 원문 JSON/TypeScript/Markdown 자료를 포함합니다. 상위 교육/Workspace/박경찬 Space와 공통 하네스 및 다른 분야는 포함하지 않습니다. 학생 개인정보가 있으므로 승인된 비공개 저장소에서만 보존합니다.

manifest.json의 files는 각 파일의 SHA-256, 원문 reference, 출처 Page/block을 연결합니다. assets의 원문 UTF-8 바이트 해시를 원본 도구가 반환한 SHA-256과 모두 대조했습니다. Page는 원래 블록 ID/hash/sequence/content/metadata를 보존한 JSON 스냅샷입니다. 원래 불명확한 사실을 정정하지 않았습니다. Page 내 원래 첨부 식별자는 오프라인 manifest로 대응하며, 보장된 다운로드 URL이 아닙니다.

이 묶음 자체는 앱과 Repo 동기화, 배포, 독립 자동화 재연결, 또는 Space 삭제 성공을 뜻하지 않습니다. 삭제 전 repo merge/restore 및 운영 의존성 검증이 별도로 필요합니다. 원시 실시간 브라우저 DOM은 포함하지 않습니다.
