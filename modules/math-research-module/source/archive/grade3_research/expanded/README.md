# 세부단원별 유형·창작 예시 확장

## 설계와 범위

- 기존 `four_level_hierarchy.json`의 88개 내용 노드, 기존 33개 초3 유형, 34개 연결 유형과 선수 관계를 삭제하거나 다시 번호 매기지 않는다.
- 초3 본체의 기존 세부단원 55개를 모두 직접 연결한다. 기존에 직접 유형 연결이 없던 `HC21-d2`도 보완한다.
- 출판사의 공개 차시 목차는 내용 범위의 근거이다. 세분유형 목록과 예시문항, 정답, 풀이, 오개념은 직접 작성했으며 출판사 문항의 복제나 출판사 유형표의 전수 조사가 아니다.
- 숫자·맥락만 달라진 5쌍은 유형을 늘리지 않고 variants로 보존했다. 다른 자리의 올림, 몫의 0, 나머지 해석, 예/비예 조건 등 판단 과정이 다른 경우는 세분유형으로 구분했다.
- 국가 교육과정은 3~4/5~6학년군 기준이다. `observedPlacement`의 학기는 확인한 교과서·공식 예시 편성을 뜻하며 전국 공통의 법정 배치를 뜻하지 않는다.
- 상위 학년 연결에서도 기존 core-related 내용만 문제화한다. boundary-support 네 내용은 경계 지원 기록으로 유지하며 별도 시험 범위로 확대하지 않는다.
- 내용의 부모-자식 관계는 분류 관계이다. 선수학습 관계와 같은 뜻이 아니며, 문항을 제시했다고 학생 숙달이 확인된 것도 아니다.

## 초3 확정 결과

- 55개 세부단원 / 105개 세분유형 / 110개 창작 예시(변형 5개 포함)
- 기존 33개 유형의 연결 누락 0개
- 128개 수치 등식 자동 검산 통과
- `core_detail_expansion.json`: 구조화 데이터
- `core_detail_examples.md`: 사람이 읽는 전체 예시집
- `core_expansion_validation.json`: 검산식 및 커버리지 결과
- `build_expansion.py`, `core_rows.txt`: 재생성 가능한 원자료와 검증기
- `expansion_schema.ts`: 기존 스키마와 별도의 추가 스키마
- `multiplication_mindmap_sample.md`: 19노드의 소형 마인드맵 트리

개념·조건·풀이의 의미는 작성자 검토를 거쳤다. 자동 검산은 수치 등식에 한정되며 교육적 적합성 전체를 자동으로 입증하지 않는다. 기존 파일의 검증 기록은 상위 디렉터리의 `validation.json`을 보존한다.

## 상위 연결 및 통합 확정 결과

- 직접 연결 11내용을 27세부단원, 46세분유형, 60창작 예시(변형 14개)로 확장했다.
- 경계 지원 4내용은 원래 기록 그대로 보존하며 문항을 붙이지 않았다.
- 통합 합계: 82세부단원, 151세분유형, 170창작 예시(변형 19개), 수치 검산 220건.
- 기존 초3 33유형과 상위 34유형은 모두 추적 가능하다.
- `upper_detail_expansion.json`, `upper_detail_examples.md`, `upper_detail_validation.json`: 상위 연결 확장 결과.
- `combined_validation.json`, `validate_combined.py`: 전체 참조·경계 보존·학년군·필드·커버리지 검사와 최종 데이터 해시.
- 독립 교차검토에서 지적한 외접 조건의 모호함, 해당 계산에 맞지 않는 오개념, 올림 조건 구분을 초3 데이터에 반영했다. 상위 유형의 포괄 제목과 소수 조건 제목도 수정했다.
