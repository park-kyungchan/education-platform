## 데이터 모델: 다른 축을 한 계층에 섞지 않기

계층은 학기→단원→세부 개념→문제 유형이다. 계산 조건은 같은 유형 안의 변형 태그로 둔다.

1. 내용 노드: 세 자리×한 자리, 두 자리÷한 자리, 반지름과 지름 등.
2. 문제 유형: 학생이 해결해야 할 핵심 과제로 구분한다. 계산하기/원리 설명하기/오류 수정하기/조건으로 추론하기/생활 상황 해석하기 등.
3. 계산 조건 태그: 자리 수, 받아올림 위치·횟수, 자리 바꾸어 나눔 여부, 나머지 유무, 몫의 중간·끝 0, 곱에 포함된 0 등. 조건 조합마다 유형을 새로 만들지 않는다.
4. 표현 태그: 가로식, 세로식, 수모형, 배열 그림, 말, 표, 원 도식, 실물 조작.
5. 인지 행동 태그: 계산, 설명, 비교, 추론, 검증, 모델링, 작도. 대표 행동은 하나, 보조 행동은 여러 개 가능.
6. 맥락 태그: 맥락 없음/같은 묶음/배 비교/등분/포함/포장·자리 배정/무늬 등.
7. 수준 태그: 기초/연결/확장. 이는 실제 학생 정답률로 보정하기 전의 설계상 수준이며 실측 난도가 아니다.

같은 ‘124×3’이라도 계산 요구와 풀이 오류 수정 요구는 유형이 다르다. 반면 받아올림 유무만 다른 직접 계산 문제는 같은 유형의 다른 계산 조건이다. 나머지를 남기는 상황과 몫을 하나 늘려야 하는 상황은 답의 해석 원리가 달라 별도 대표 유형으로 볼 수 있다.

## 2-1 곱셈

### 내용 노드와 권장 진행

- M0 선수: 자릿값과 수 분해, 곱셈구구, 두 자리×한 자리, 받아올림 덧셈.
- M1 세 자리×한 자리: 자리별 곱의 합→세로셈→받아올림과 0 처리.
- M2 ×10 및 몇십 곱하기: 한 자리·두 자리×10→몇십×몇십·두 자리×몇십. 두 자리 곱셈의 십의 자리 부분곱을 이해하는 연결 노드.
- M3 한 자리×두 자리: 곱하는 수를 십과 일로 나누어 곱한 뒤 합하기.
- M4 두 자리×두 자리: 두 부분곱의 의미→정렬→합하기.
- M5 곱셈 종합 활용: 어림·관계·빈칸·오류·생활 문제. 단, 원리 설명과 검증은 M1부터 병행한다.

- D1 몇십÷한 자리: 십 묶음으로 나누기→십을 일로 바꾸어 나누기.
- D2 두 자리÷한 자리, 나누어떨어짐: 자리별 몫과 세로셈.

## 2-3 원

### 내용 노드와 권장 진행

- C0 선수: 원 모양의 직관적 인식, 점·선분, 길이와 자 사용, 두 배·반.
- C1 중심·반지름·지름의 식별: 중심과 원 위 점의 역할 구분.
- C2 성질: 한 원의 반지름은 같음, 지름은 반지름의 두 배, 같은 크기 비교.
- C3 컴퍼스 작도: 바늘 위치=중심, 벌린 길이=반지름.
- C4 조건에 맞는 원·무늬 구성: 중심과 크기 조건 적용, 결과 설명.

| C-T09 | C3 | 작도 과정 오류 진단 | 반지름 3cm 원을 그리다가 벌림이 4cm로 변함. 맞는 원인가? → 아니다, 같은 벌림을 유지 | 중심 고정·벌림 고정의 역할을 각각 확인 |
| C-T10 | C4 | 여러 원으로 조건·무늬 구성 | 중심 O가 같고 반지름 2cm와 4cm인 원 두 개 그리기 → 같은 바늘점, 벌림만 변경 | 동심원 용어 암기는 요구하지 않음 |
| C-T11 | C4 | 결합 도형의 길이 추론 | 중심이 같은 수평선 위에 있고 바깥쪽에서 한 점으로 맞닿은 같은 크기 원 2개. 각 지름 6cm. 두 원의 전체 가로 길이 → 12cm | 접함·일직선 조건을 그림/문장으로 명시. 선택 확장, 원주·넓이 아님 |
| C-T12 | C4 | 그림에서 성립하는 조건 설명 | 중심은 다르고 컴퍼스 벌림은 모두 3cm로 그린 두 원. 크기는? → 같다 | 위치와 크기를 구분, 벌림=반지름 |

작도 문제는 숫자 정답만으로 완료 처리하지 않는다. 중심 위치, 반지름 설정, 벌림 유지, 원의 완성도를 관찰한다. 디지털 도구에서는 화면 확대율과 실제 cm를 혼동하지 않도록 수치 조건으로 평가하고, 물리 컴퍼스 조작은 별도 실기 근거로 남긴다.

## 선수 관계: 공식 지정이 아닌 수업 설계 제안

화살표 A→B는 B를 원리 있게 학습할 때 A가 도움이 되거나 선행 확인이 필요하다는 뜻이다. 모든 학생에게 반드시 고정된 한 줄 진도를 강제하는 뜻은 아니다.

| 선행 | 후행 | 이유 | 관계 강도 |
|---|---|---|---|
| 자릿값·수 분해 + 곱셈구구 | M1 | 각 자리의 곱과 받아올림 이해 | 핵심 |
| M1 + ×10의 자릿값 이해 | M2 | 몇십 배의 크기 해석 | 권장 |
| M2 + 곱셈구구 | M3 | 십과 일의 부분곱 | 핵심 |
| 두 자리×한 자리 + M2 | M4 | 두 부분곱 산출·정렬 | 핵심 |
| M3 | M4 | 두 자리 승수의 구조가 같은 쉬운 사례 | 권장 |
| 곱셈구구 + 등분/포함 의미 | D1 | 몫의 크기와 뜻 | 핵심 |
| D1 + 자릿값 | D2 | 십을 일로 바꾸어 나누기 | 핵심 |
| D2 | D3 | 계산 절차에 남는 양 해석 추가 | 권장 |
| D3 + 곱셈·나눗셈 역관계 | D4 | 검산식과 나머지 조건 | 핵심 |
| D2 + D3 | D5 | 세 자리로 절차 확장 | 핵심 |
| M1 | D5/D4 | 세 자리 계산의 검산 지원 | 권장 |
| D3 | D6의 나머지 해석 | 몫과 나머지의 상황적 의미 | 핵심 |
| 원 모양 + 점·선분 | C1 | 요소를 구분할 언어 | 핵심 |
| C1 + 두 배·반 | C2 | 반지름과 지름 관계 | 핵심 |
| C1 + 길이 측정 | C3 | 중심과 벌림을 설정 | 핵심 |
| C2 + C3 | C4 | 크기·위치 조건에 따른 구성 | 핵심 |

단원 간에는 곱셈 계산이 나눗셈 검산을 돕지만, 원 전체를 곱셈·나눗셈 완수 뒤로 잠그지 않는다. 원의 두 배·반은 이미 익힌 간단한 수 범위에서도 배울 수 있다.

## 시각화·진단에 넘길 구현 규칙

- 기본 화면: 3개 단원 카드→내용 노드 펼치기→유형 목록. 사용자 번호를 첫 라벨로 유지하고 출판사 순서는 별도 메타데이터로 표시.
- 내용 계층은 실선, 선수 관계는 선택적으로 보이는 점선으로 구분. 한 화면에 전부 펼치지 않기.
- 선택 유형 상세: 목표, 대표 예시, 정답·판정, 계산 조건 태그, 대표 오개념, 선행 내용, 근거의 수준.
- 원형 도형·배열 그림은 유형의 표현 자산이지 새로운 유형 노드가 아님.
- 교수 설계 추천을 실제 학생의 ‘미학습/미숙달’로 표시하지 않기. 학생 상태는 별도 실제 풀이 근거가 들어와야 생성.
- 유형별 정답률을 받아올림/0/나머지 조건별로 교차 분석하되, 표본 수가 작으면 ‘판정 보류’로 표시.
- 예제 수치가 바뀌어도 안정 ID 유지. 같은 조건의 반복문항 수가 유형의 가짓수로 계산되지 않게 하기.
- 제외: 두 자리 제수, 소수 몫, 원주·원주율·원의 넓이, 복잡한 혼합계산 규칙, 출처 없는 상위권 경시 유형. 별도 확장 요청이 있을 때만 분리 추가.
