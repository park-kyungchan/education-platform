# 초3 예제풀이 미시행동 설계: 학습심리학 근거와 적용 한계

검증일: 2026-10-13. 이 문서는 연구자가 만든 설계 원리와 관찰 틀이며, 표준화된 검사·검증된 처치·Freudenthal의 원문 행동 분류가 아니다. 기존 수학적 설계와 학습심리학을 혼합 인용하지 않는다. 수학적 구조 선정 이유는 기존 연구에, 지도 방법의 근거는 아래 자료에 따로 연결한다.

## 선정 원리 세 묶음

1. **체계적 지도와 표상 연결**. IES21은 초등 수학 학습에 어려움을 보이는 학생을 위한 공식 중재 지침이다. 필요한 선행 지식을 먼저 확인하고, 목표 관계가 보이는 모델링 뒤 학생의 반응을 확인한다. 구체물·그림·식의 대응을 학생이 직접 가리키게 하는 설계는 이 프로젝트의 적용이다. 구체물을 만졌다는 사실만으로 개념을 이해했다고 판단하지 않는다. CRA는 학생별 고정 학습 양식도, 어떤 개념에나 강제하는 일방향 사다리도 아니다. 이미 식으로 이해하는 학생에게 모든 구체물 단계를 재수행시키지 않는다.
2. **풀이 예제, 탐색 부담 조절, 지원 줄이기**. IES07의 예제-문제 교대 권고를 활용한다. SC85와 RAMS02는 예제와 점진적 빈칸화의 실험 근거지만 중등·대학 맥락이다. 초3에서 긴 지시를 분절하고 필요한 표상을 가까이 제시하는 것은 적용 가설이다. ‘인지부하가 감소했다’고 측정 없이 단정하지 않는다. 학생이 다음 수학적 판단을 수행할 수 있다는 관찰 증거가 생기면 표시·질문 카드·완성된 식을 하나씩 덜 제공한다. 실패하면 마지막으로 제거한 지원만 복구한다. 무조건 마지막 단계부터 지우거나 정답률 임계치를 연구 검증치처럼 쓰지 않는다.
3. **초점을 정한 자기설명과 내용 확인**. RJ06은 초3–5의 등식 동치 실험으로 학년이 가깝지만 연구 과제가 다르다. 독립 개념 지식 측정에서는 추가 향상이 없었다는 결과를 반드시 함께 보존한다. 본 설계에서는 ‘왜?’만 반복하지 않고 ‘남은 2개로 한 봉지를 더 채울 수 없는 까닭을 그림으로 보여줘’처럼 관계를 특정한다. 말하기의 길이·유창성 대신 수학적 근거를 본다. 가리키기·그림·조작도 응답으로 인정한다.

원문 정보와 정확한 링크·연구대상·검증 범위는 psychology_sources.json에 있다. 모든 개별 행동에 붙인 처치는 project_application_inference이며, 원 연구가 그 문항·그 행동을 직접 검증했다는 의미가 아니다.

## 행동 분리 기준

다음 경계에서만 별도 행동으로 나눈다.
- 확인하는 수량이나 단위가 달라진다: 전체 낱개 / 묶음 크기 / 묶음 수 / 남은 낱개.
- 표상이 바뀐다: 실제 묶음 → 그림 → 곱셈식 → 나눗셈 기록.
- 서로 다른 오류 원인을 구분해야 한다: 자리값 이해 / 구구 회상 / 받아올림 기록.
- 정당화 조건이 다르다: 전체 복원식 / 남은 수가 제수보다 작음.
- 학습 증거의 성격이 달라진다: 안내된 실행 / 설명 / 지원 없는 전이 / 경계 반례.

단순히 연필을 듦·점을 하나 그림·다음 칸으로 이동함을 기계적으로 분절하지 않는다. 반대로 ‘개념을 이해한다’, ‘주의한다’, ‘풀이한다’만으로 행동을 쓰지 않는다. 이는 관찰할 수 없는 상태거나 지나치게 큰 단위다. 각 행동은 cue, observableStudentAction, expectedUnderstanding, mathematicalPurpose, designIntent, teacherCheck, likelyError, scaffold, fading, separationReason, evidence를 갖는다.

## 38÷6 샘플의 핵심 설계 문제

전체 상세 16행동: action_microsteps_sample_division.json. 16은 분석 결과이며 모든 문항의 목표 개수가 아니다.

1. 가득 찬 봉지 수와 남는 낱개 수를 찾아 표시한다.
2. 38을 전체 구슬 수와 연결한다.
3. 6개씩을 한 봉지 크기로 나타낸다.
4. 동일한 6개짜리 두 번째 묶음을 만든다.
5. 전체를 중복·누락 없이 6개씩 묶고 2개를 남긴다.
6. 묶음을 단위로 6봉지를 센다.
7. 남은 낱개 2개를 따로 센다.
8. 2개로 추가 6개 묶음을 만들 수 없는지 판단한다.
9. 6×6의 두 6을 묶음 크기와 묶음 수에 각각 연결한다.
10. 36+2=38로 전체를 복원한다.
11. 38÷6=6…2로 기록한다.
12. 5봉지·8개라는 불완전 분할에서 한 봉지를 더 만든다.
13. 전체 보존과 추가 묶음 불가라는 두 근거로 설명한다.
14. 38÷5를 지원 없이 시도하여 제수·몫 역할 혼동을 검사한다.
15. 36÷6으로 0 나머지 경계를 검사한다.
16. 남은 구슬까지 모두 담는 경우 7장 필요함과 몫 6을 구별한다.

특히 38÷6은 제수와 몫이 모두 6이므로 정확한 숫자만으로 역할 이해를 확인할 수 없다. 38÷5(몫 7, 나머지 3)는 이 우연한 숫자 일치를 깨는 전이 검사다. 38=6×5+8은 수량 보존에는 맞지만 완료된 나눗셈의 답은 아니다. 이 두 특징은 문항 고유의 수학적 설계 이유이며 일반 심리학 이론에서 자동으로 나오지 않는다.

## 학생 실행과 연구용 상세의 분리

연구자는 모든 행을 비교할 수 있다. 학생에게는 현재 질문과 필요한 표상만 보이며, 분석용 용어·오류 목록·모든 설명을 동시에 제시하지 않는다. 복잡한 연구 문항도 허용하지만 실행 시 선수 지식, 읽기 부담, 도구 조작 가능성, 분절 수업 여부를 명시한다. 준비가 된 학생은 여러 행동을 묶어서 수행할 수 있다. 준비가 안 된 학생은 작은 수나 실제 물체로 돌아간다. 지름 판별은 중심 통과·끝점 조건과 방향 변화를 분리하고, 컴퍼스 조작 정확도와 개념 판별을 별도 기록한다.

## 자료 수집 최소 규칙

- 실제 관찰: 학생의 말·표시·그림·식·수정, 제공한 도움 종류와 시점, 독립 수행 여부.
- 해석: 기대 이해를 뒷받침하는 증거와 경쟁 설명을 따로 쓴다. 맞힌 이유를 추정만으로 확정하지 않는다.
- 검사: 안내된 예제 성공, 새로운 수·배치에서의 전이, 경계 사례, 가능하면 지연 확인을 구분한다.
- 학습 효과: 비교 설계 없이 ‘효과가 입증됨’, ‘개념 형성 완료’, ‘인지부하 감소’를 선언하지 않는다.
- 학생 특성: 나이로 사고 가능성을 고정하지 않는다. 학습 양식 유형을 부여하지 않는다. 미세운동·읽기·언어 표현·계산 사실 회상의 부담을 개념 오류와 분리한다.
