Original Codex startup entrypoints and changed operational files are retained as inactive .source historical records. Historical source verification and current runtime validation are separate.

The 4 canonical domain workpacks and curriculum boundary are absent from the original export. Later workspace inputs are reported as unverified, regardless of a matching declared checksum.

RUNTIME_VALIDATION_RECEIPT.json records verification on the preparation machine. It does not establish successful installation or execution on the target VPS.
