# 도형과 측정 콘텐츠 원본

공식 도형과 측정 38개 성취기준을 합동·대칭, 입체, 측정, 작도, 원, 닮음, 직각삼각형과 삼각비의 구조로 펼친 콘텐츠 초안입니다. 공식 범위와 모델 작성 설명·관계의 근거를 분리했습니다.

## 현재 원본 · 리비전 3 · Schema 1.2

정의·설명·예제·조건·관계 근거의 2,736개 본문 필드를 검토하여 수식 구간 535개와 일반 산문을 명시적으로 구분했습니다. 원래 문장, 수치 예제와 수학적 조건은 그대로이며 LaTeX 표현만 별도 확장에 추가했습니다.

## 범위와 설명

정확한 학년은 null로 두고 초5∼6·중1∼3의 공식 학년군만 연결했습니다. 볼록 다각형·다면체의 범위, 초등 원뿔·각뿔 전개도 제외, 중등 삼각비 관계식·원과 비례 성질 제외 등의 경계를 조건에 보존했습니다.

대학 수준의 등거리변환·벡터·정보 손실 등의 설명은 고급 렌즈로 분리했습니다. 학생에게 새로 요구하는 필수 선수로 처리하지 않습니다.

## 검증 상태

공통 관점과 수와 연산·변화와 관계 workpack을 함께 사용한 엄격 구조 검증에서 오류 0을 확인했습니다. 수치·도형 사례 41개와 LaTeX 원문 46개를 검사했습니다.

서로 다른 쌓기나무가 같은 위·앞·옆 윤곽을 만들 수 있다는 반례도 계산으로 확인했습니다. 일반 정리의 독립 증명 검토, 예제와 맞는 기하 그림, KaTeX 화면 렌더 검수는 별도 열린 항목입니다.
