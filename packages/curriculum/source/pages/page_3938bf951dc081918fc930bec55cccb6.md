# 공간 지도 수식 렌더링 개정 3

## 보존된 샘플의 수학 정정

샘플 r2의 ‘공통 분모 = 원래 각 분모의 양의 공배수’라는 표현은 일반 정의로는 너무 좁습니다. 공통 분모는 값이 같은 분수들로 나타냈을 때 함께 쓰는 분모입니다. 공배수를 택하는 것은 통분하는 한 방법이며, 2/4와 3/6은 모두 1/2로 나타낼 수 있습니다.

기존 화면·JSON은 당시 샘플로 보존합니다. ‘공배수 필수 선행’은 공배수로 통분하는 설명 경로의 주장으로 읽어야 합니다. 수정된 정의·조건·관계는 [수와 연산 콘텐츠 원본](page:page_ee8dd4415f888191a764bacae70b0e43) 리비전 3에 반영했습니다.

KaTeX로 분수·근호·거듭제곱을 실제 MathML 수식으로 생성한 개정판입니다. 기호를 펼치면 큰 수식과 의미를 함께 보고, 예시의 한국어 문장은 유지하면서 수학 부분을 렌더링합니다.

현재 내용은 기존 12개 개념 표본입니다. 전체 초5–중3 자료와 고등학교 내용이 모두 연결된 상태는 아닙니다. 고등학교 표기는 렌더러 문법 시험에만 사용했습니다.

## 수식 확인

검색창에서 통분, 동치분수, 제곱근과 근호, 지수법칙을 찾아 기호를 펼쳐 보세요. 17개 기호와 10개 예시의 수학 부분을 KaTeX로 변환했습니다. 인라인과 큰 수식 표시를 함께 지원합니다.

## 렌더링과 추적

[KaTeX 0.19.0](https://katex.org/docs/api)의 실제 파서로 LaTeX를 MathML로 사전 생성합니다. LaTeX 원문과 기호 ID·리비전·부모·원문 해시, 렌더러 옵션 및 결과 해시를 함께 보관합니다. 화면 실행에 CDN이나 외부 글꼴이 필요하지 않습니다.

원문이나 리비전이 달라지면 이전 수식을 그대로 사용하지 않고 확인 표시와 원문을 보여 줍니다. 지원하지 않는 명령과 잘못된 LaTeX도 같은 방식으로 드러냅니다. 원본을 바꾼 뒤에는 렌더링 자료를 다시 생성해야 합니다.

## 검증 범위

실제 KaTeX 렌더러 검사 17개, MathML 출력 218개의 XML 검사, 화면 모의 검사 17개를 통과했습니다. 별도로 canonical 표기 33개와 다른 영역 표기 83개를 검사했습니다. 고등학교 표기 15개는 문법 시험용이며 현재 교육 내용에 추가하지 않았습니다.

호스트의 실제 MathML 표시, 작은 화면의 수식 스크롤, 스크린리더 발음과 실제 키보드 동작은 아직 검증하지 못했습니다. 현재 지도에는 기존 12개 개념만 연결돼 있습니다.
