# Palantir Ontology 수학 적용 제안

Palantir의 객체·관계·행동 모델을 MathEducation에 적용한 타입 기반 제안입니다. 내용 정체성, 교육과정 배치, 설명 관점, 관계 주장을 분리하고, 변경과 복원은 읽기 전용 모의 상태로 검증합니다.

## 적용 상태

| 항목 | 상태 |
| --- | --- |
| 저장 형식 | 타입 지정 JSON과 엄격한 JSON Schema |
| 구성 | 객체 75개 · 객체 타입 계약 11개 · 공식 문서 19개 |
| 검증 | 구조와 변경 모의 검증 29개 통과 |
| 기존 자료 | 개념 UI 샘플과 관계 ledger 원본 보존 |
| 변경 예시 | 관련 관계를 도움되는 선행으로 바꾸는 미승인 제안 |
| 운영 상태 | Foundry 미배포 · 호환성 미검증 · 실제 승인과 반영 없음 |

## 모델의 네 축

| 축 | 타입 | 역할 |
| --- | --- | --- |
| 내용 정체성 | MathConcept · MathTerm · MathNotation | 개념과 용어·기호를 독립 식별자로 관리 |
| 교육과정 배치 | CurriculumStandard · CurriculumAlignment | 공식 기준과 매핑 주장을 구분 |
| 설명 관점 | Perspective · Explanation | 초5부터 중3까지의 내용에 대학 수준 설명도 연결 |
| 관계와 변경 | DependencyAssertion · ChangeProposal · RevisionEvent | 조건·근거·제안·변경 이력을 보존 |

학년 배치와 성취기준 연결은 아직 공식 원문 대조 전입니다. 대학 수준 설명은 해당 학습자의 필수 선수로 처리하지 않습니다.
