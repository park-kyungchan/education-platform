# 한국어 표준 용어와 영어 병기 근거

2022 개정 교육과정과 교과용도서 편수자료에 맞추어 한국어 명칭을 검토하고 영어를 함께 표시합니다. 더 잘게 나눈 설명용 명칭은 공식 필수 용어와 구분합니다.

## 표시 항목과 번역 근거

개념 313개, 용어 421개, 기호 설명 203개, 주제 43개, 공식 영역 4개의 표시 항목을 연결했습니다. 영어는 편수자료에 기재된 외국어 295개, 검토 번역 250개, 보충 번역 439개로 구분합니다. 이는 교육과정의 공식 영어 번역 목록을 뜻하지 않습니다.

## 검증과 변경 기록

한국어 명칭 204개 필드와 설명 416개 필드를 교정했습니다. 기존 ID와 관계 연결, 기호식, 수식 조각을 보존하고 원문·리비전 해시로 변경을 검증했습니다.
