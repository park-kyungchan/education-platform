# 수학 관계 변경과 복원 모의 검증

분수 덧셈 → 유리수 덧셈의 관계를 related에서 helpful_prerequisite로 바꾸는 제안과, 원상태를 새로운 리비전으로 복원하는 과정을 읽기 전용으로 계산했습니다. 특정 관계 변경에 대한 사용자 승인은 기록하지 않았으며 기존 그래프는 바뀌지 않았습니다.

## 변경 예시

| 단계 | 관계 분류 | 리비전 | 실제 반영 |
| --- | --- | --- | --- |
| 기준 상태 | related | 1 | 기존 샘플 복사본 |
| 변경 후 가상 상태 | helpful_prerequisite | 2 | 없음 |
| 보상 복원 후 가상 상태 | related | 3 | 없음 |

변경 이유: 양의 분수 덧셈을 알면 부호 있는 유리수 덧셈을 설명하는 데 도움이 된다는 교수 관점을 비교합니다. 필수 선수로 승격하거나 보편적인 유일 학습 순서로 주장하지 않습니다.

## 승인과 복원의 경계

현재 적용 준비 상태는 false입니다. 예시 관계에 대한 구체적 승인과 배포된 실행 환경이 모두 없으므로 실제 변경은 수행하지 않습니다. 복원 예시는 revision 1을 덮어쓰지 않고 1→2→3 이력을 남기는 자체 계약입니다.

Palantir 기본 Undo는 적용 사용자·시점·최신 편집·저장소 등의 제한이 있고 외부 알림이나 웹훅은 되돌리지 않습니다. Scenarios도 과거 버전 저장 도구가 아닙니다. [Action Undo](https://www.palantir.com/docs/foundry/action-types/action-reverts) · [Scenarios](https://www.palantir.com/docs/foundry/ontology/overview-ontology-scenario)

## 검증 범위

JSON 구조, 식별자, 계층, 참조, 리비전·변경 해시, 특정 관점의 필수 선수 순환을 검사했습니다. 자연어 적용 조건의 논리적 함의, 교육 효과, 배포된 권한·트랜잭션 보장은 검증 범위에 포함되지 않습니다.
