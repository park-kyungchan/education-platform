# 에이전트 작업 규칙

MathEducation 작업에서 읽을 공통 맥락과 수학 정본을 연결합니다. 학원 학생 기록과 추상 수학 콘텐츠를 섞지 않고, 교육과정 근거·모델 보충 설명·사용자 관점을 관계별로 구분합니다.

## 로드 범위

선택한 개념·관계·출처와 해당 버전의 Schema를 먼저 읽습니다. 영역 전체를 읽었다는 주장과 일부 관계를 읽은 사실을 구분하며, 원문 변경 시 이전 수식·번역·근거 연결을 재검증합니다.

콘텐츠 작업은 math.content, 용어·수식 변경은 math.terms_and_formulas, 화면의 위치·필터·선택은 math.view_state 경로를 선택합니다.

## 고정할 현재 버전

최종 release manifest의 canonical Schema 1.3.0과 extension registry 1.3.0, 작성 계약 1.1.0을 대조합니다. 기존 계약 Page의 상단 1.2 표기와 과거 ZIP은 보존본이며, 아래의 한영 표기 계약에 연결된 실제 1.3 파일을 사용합니다.

공식 boundary와 선택 workpack의 필요한 레코드·EvidenceReference·CurriculumAlignment·Perspective·ContentGap을 읽습니다. 모든 대용량 정본을 매 작업의 초기 맥락에 넣지 않으며, 다른 영역을 참조하는 변경은 그 영향 대상도 읽습니다.

## 근거와 의미의 경계

MOE-2022-33-annex-8의 판본·원문 위치는 공식 범위와 성취기준 근거입니다. 모델 보충 설명과 사용자 관점은 별도 source/version으로 유지합니다. 공식 학년군과 개별 학년 배치를 분리하고 근거가 없으면 yearPlacement는 null입니다.

selected 상태는 사용자 approved가 아닙니다. 관계 종류·방향·DAG 정책은 registry에서 읽고 같은 관점의 선택된 관계에 적용합니다. 현재 Action의 contract_only 상태를 실제 실행 도구로 표현하지 않습니다.

한영 명칭과 본문 수식 수정은 해당 확장 Schema까지 읽습니다. 원문 해시와 명시 구간을 보존하고 영향받은 주석·view·cache를 재검증합니다. 학원 학생 자료를 이 추상 정본에 넣지 않습니다.
