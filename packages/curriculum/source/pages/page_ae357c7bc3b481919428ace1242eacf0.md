# 개념 지도 UI 샘플

## 보존된 샘플의 수학 정정

샘플 r2의 ‘공통 분모 = 원래 각 분모의 양의 공배수’라는 표현은 일반 정의로는 너무 좁습니다. 공통 분모는 값이 같은 분수들로 나타냈을 때 함께 쓰는 분모입니다. 원래 분모의 공배수를 택하는 것은 통분하는 한 방법입니다. 예를 들어 2/4와 3/6은 모두 1/2이므로 공통 분모 2를 쓸 수 있습니다.

이 페이지와 연결된 기존 화면·JSON은 당시 샘플을 보존합니다. 그 안의 ‘공배수 필수 선행’은 공배수로 통분하는 설명 경로의 주장으로 읽어야 하며, 모든 통분 경로의 절대 조건으로 보지 않습니다. 수정된 정의·조건·관계는 [수와 연산 콘텐츠 원본](page:page_ee8dd4415f888191a764bacae70b0e43)의 리비전 3에 반영했습니다.

개념 12개로 위계 탐색, 선수 관계, 용어·기호 상세와 검증 상태를 비교하는 샘플입니다. 정식 교육과정 전체 지도나 학습 진단 결과가 아닙니다.

위계는 개념을 분류하는 위치입니다. 선수 관계는 학습 의존성을 나타내며, 표현·관련 관계와 분리해 보관합니다. 이 화면은 연결된 구조화 원본의 한 버전을 보여 줍니다.

## 화면 선택 기준

Page는 탐색·직접 편집·댓글에, 내장 탐색기는 개념 선택·관계 전환·검토 항목 확인에 사용합니다. 원본 파일 변경은 화면에 자동 반영되지 않으며, 동일 리비전에서 다시 생성해야 합니다.

[Space 공식 안내](https://help.openai.com/en/articles/20001549-getting-started-with-space-in-chatgpt) · [2022 개정 교육과정 공식 발표](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=294&boardSeq=93459&lev=0&searchType=null)

교육과정 발표 자료는 배경 근거입니다. 개념별 성취기준 대응과 학년 배치는 별책 8 원문 검토 전이며, 표시는 UI 배치 제안입니다.
