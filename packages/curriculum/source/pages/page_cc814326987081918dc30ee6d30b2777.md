# 수학 콘텐츠 타입과 변경 계약

## 현재 계약 · Schema와 registry 1.2

본문 수식을 위한 math:extension:math-text를 추가했습니다. 각 필드의 원문 해시, 일반 텍스트 구간, 명시적 LaTeX 구간을 저장하며 구간을 이어 붙인 결과가 원문과 정확히 같아야 합니다. 기존 1.0·1.1 원본도 계속 읽습니다.

원문이 바뀐 필드는 기존 수식을 그대로 적용하지 않고 pending_review 상태로 돌아갑니다. 수정되지 않은 구간은 보존하고, 레코드·작업 묶음의 리비전과 이전 원본을 유지합니다. 실제 사용자 승인이나 Foundry 실행을 의미하지 않습니다.

## 작성과 검증

도메인별 workpack은 공식 학년군·영역·성취기준의 ID를 참조합니다. 정확한 학년 배치는 별도 근거가 없으면 null로 둡니다. 필수 선수의 순환은 같은 관점에서 선택한 관계에만 검사합니다.

43개 회귀 검사는 잘못된 타입, 범위, 참조, 중복 ID, 리비전, 등록되지 않은 확장, 근거 없는 승인 상태, 변경 후 coverage 등을 포함합니다. 이 검사는 수학적 참이나 수업 효과를 자동으로 보증하지 않습니다.

## 확장과 변경

새 관계·Action·확장 필드는 목적, 적용 타입, 값의 Schema, 검증 규칙과 예제를 함께 등록합니다. 기존 ID는 이름이나 학년이 바뀌어도 유지하고, 의미를 나누거나 합칠 때는 명시적인 ID 대응과 새 리비전을 남깁니다.

현재 도구는 로컬 초안의 구조 검증용입니다. 사용자의 승인 사실을 임의 문자열로 인증하지 않으며 운영 환경의 권한·트랜잭션 시스템을 배포했다는 뜻은 아닙니다.
