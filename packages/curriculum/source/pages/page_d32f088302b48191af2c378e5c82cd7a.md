# 공간 지도 탐색 개정 2

## 보존된 샘플의 수학 정정

샘플 r2의 ‘공통 분모 = 원래 각 분모의 양의 공배수’라는 표현은 일반 정의로는 너무 좁습니다. 공통 분모는 값이 같은 분수들로 나타냈을 때 함께 쓰는 분모입니다. 공배수를 택하는 것은 통분하는 한 방법이며, 2/4와 3/6은 모두 1/2로 나타낼 수 있습니다.

기존 화면·JSON은 당시 샘플로 보존합니다. ‘공배수 필수 선행’은 공배수로 통분하는 설명 경로의 주장으로 읽어야 합니다. 수정된 정의·조건·관계는 [수와 연산 콘텐츠 원본](page:page_ee8dd4415f888191a764bacae70b0e43) 리비전 3에 반영했습니다.

검색으로 개념·용어·기호를 바로 찾고, 지도를 유지한 채 상세 패널을 여는 개정판입니다. 전체 영역 → 설명용 묶음 → 개념의 경로와 선택한 개념의 이웃을 함께 볼 수 있습니다.

공식 4개 영역과 초5–6·중1–3 학년군을 구분했습니다. 개념 내용은 기존 원본 r2의 12개 표본이며, 표본의 영역 연결과 교육과정 성취기준 대응은 검토 중입니다.

## 연결 상태

현재 연결된 데이터는 기존 원본 r2의 개념 12개입니다. 전체 초5–중3 내용이 연결된 상태는 아닙니다.

새 canonical 데이터의 읽기 전용 변환기는 계약 예시 3개 개념과 2개 관계로 검증했습니다. 원본 ID와 상태를 보존하고, 선택한 관점의 필수 선행만 순환 검사하며, 개별 학년을 추정하지 않습니다. 실제 전체 데이터 연결은 별도 단계입니다.
