# 변화와 관계 콘텐츠 원본

비·비율·비례에서 문자와 식, 방정식·부등식, 좌표와 함수, 이차식까지 공식 성취기준 27개를 연결한 콘텐츠 초안입니다. 개념 93개, 용어 119개, 기호 83개의 의미와 적용 조건을 구조화했습니다.

## 현재 원본 · 리비전 4 · Schema 1.2

정의·설명·예제·조건·관계 근거의 2,099개 본문 필드를 검토하여 수식 구간 2,431개와 일반 산문을 명시적으로 구분했습니다. 원래 문장, 수치 예제와 수학적 조건은 그대로이며 LaTeX 표현만 별도 확장에 추가했습니다.

## 범위와 근거

초5∼6·중1∼3의 공식 학년군을 사용하며 정확한 학년은 지정하지 않았습니다. 공식 범위 근거와 모델 작성 설명·예제를 EvidenceReference로 구분했습니다. 대학 수준 해설은 별도 관점이며 학생의 필수 선수로 요구하지 않습니다.

## 검토와 변경

모든 내용은 production_draft입니다. 관계는 근거·조건·관점을 가진 후보이며 실제 사용에서 변경 제안과 리비전으로 수정할 수 있습니다. 독립 수학 검토의 수정 사항을 반영한 원본을 아래에 연결합니다. 교사 검토와 실제 호스트 화면의 시각 검수는 열린 항목입니다.
