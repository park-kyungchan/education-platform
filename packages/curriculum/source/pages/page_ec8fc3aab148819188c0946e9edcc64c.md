# 통분 개념 상세 샘플

## 보존된 샘플의 수학 정정

샘플 r2의 ‘공통 분모 = 원래 각 분모의 양의 공배수’라는 표현은 일반 정의로는 너무 좁습니다. 공통 분모는 값이 같은 분수들로 나타냈을 때 함께 쓰는 분모입니다. 원래 분모의 공배수를 택하는 것은 통분하는 한 방법입니다. 예를 들어 2/4와 3/6은 모두 1/2이므로 공통 분모 2를 쓸 수 있습니다.

이 페이지와 연결된 기존 화면·JSON은 당시 샘플을 보존합니다. 그 안의 ‘공배수 필수 선행’은 공배수로 통분하는 설명 경로의 주장으로 읽어야 하며, 모든 통분 경로의 절대 조건으로 보지 않습니다. 수정된 정의·조건·관계는 [수와 연산 콘텐츠 원본](page:page_ee8dd4415f888191a764bacae70b0e43)의 리비전 3에 반영했습니다.

개념 ID common-denominator의 기본 Page 보기입니다. 구조화 원본의 같은 항목을 읽기 쉽게 펼친 화면이며, 상위 UI 샘플에서 의존성 관계를 함께 탐색할 수 있습니다.

## 의미

분모가 다른 분수들을 값이 같은 분수로 바꾸어 분모를 같게 하는 과정입니다.

## 용어와 기호

- 통분: 공통 분모를 갖는 동치분수로 바꾸는 과정

- 공통 분모: 각 분모의 양의 공배수

- L/b: 분모 b를 공통 분모 L로 바꾸기 위해 곱할 배수. L은 b의 양의 배수입니다.

## 조건과 예시

분모는 양의 정수로 둡니다. 최소공배수는 효율적인 선택이지 통분의 필수 조건은 아닙니다.

1/4 = 3/12, 1/6 = 2/12로 통분할 수 있습니다. 24를 공통 분모로 사용해도 됩니다.

## 관계와 검토

- 필수 선행: 공배수, 동치분수

- 도움되는 선행: 최소공배수

- 필수 후속: 분수 덧셈, 유리수 덧셈

- 오개념: 분자가 0이 아닌 분수에서 분모만 바꾸고 분자를 그대로 두면 값이 달라집니다.

- 증거 상태: 직접 작성한 수학 예시. 공식 성취기준 대응과 학년 배치는 아직 확정하지 않았습니다.

## 대학 수준 해설

통분은 유리수의 동치류에서 분모를 일치시키는 대표원 선택입니다. b와 d가 양의 정수이고 L이 두 수의 공배수이면 u=L/b와 v=L/d는 정수입니다. aL=b(au)이므로 (a,b)와 (au,L)는 같은 유리수를 나타냅니다. 따라서 a/b + c/d = (au+cv)/L입니다. L이 최소일 필요는 없습니다.

이 해설은 사용자의 이해를 위한 설명 관점이며, 대학 수준 개념을 학생의 교육과정 필수 선행으로 추가하지 않습니다.
