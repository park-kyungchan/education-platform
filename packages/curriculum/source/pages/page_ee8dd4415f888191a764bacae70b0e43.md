# 수와 연산 콘텐츠 원본

공식 수와 연산 25개 성취기준을 개념·용어·기호·설명·관계로 펼친 콘텐츠 초안입니다. 공식 교육과정 범위와 모델이 작성한 설명을 구분해 보관하고, 정확한 학년은 지정하지 않았습니다.

## 현재 원본 · 리비전 4 · Schema 1.2

정의·설명·예제·조건·관계 근거의 1,420개 본문 필드를 검토하여 수식 구간 878개와 일반 산문을 명시적으로 구분했습니다. 원래 문장, 수치 예제와 수학적 조건은 그대로이며 LaTeX 표현만 별도 확장에 추가했습니다.

## 원본과 화면

이 페이지의 JSON이 전체 의미와 근거를 보관하는 원본입니다. 공간형 화면은 필요한 주제와 관계를 선택해 보여 주며, 화면에서 감춘 감사 정보도 원본에는 남습니다. [타입과 변경 계약](page:page_cc814326987081918dc30ee6d30b2777)을 공통으로 사용합니다.

## 검증 상태

엄격한 타입·참조·공식 범위·선택된 필수 선수 DAG 검사에서 오류 0을 확인했습니다. 수치 예제 26개를 검산했고 수식 33개의 LaTeX 원문 보존을 검사했습니다.

수학과 교수 관계의 독립 검토는 열려 있습니다. KaTeX 실제 화면 렌더링은 공간형 화면에서 확인합니다. 구조적 매핑 완료와 교육적 검증 완료를 구별합니다.
