# 범위 격자 탐색 샘플

영역과 학년 배치를 한눈에 비교한 뒤, 학습 묶음 → 개념 → 용어·기호까지 단계적으로 들어가는 화면입니다. 상단 경로에서 언제든 상위 범위로 돌아갑니다.

기존 원본 r2의 개념 12개를 그대로 사용합니다. 영역은 화면 분류이고 학년 배치는 미검증입니다. 초5·6은 묶음으로 유지하며 미구축 칸은 비워 두었습니다.

![범위 격자 탐색](visualize:fde1_bGliZmlsZV95enhlRzhWbzB5aTROX1BZU2JLMS1B_FileDrive_73e3d24e44d881918a9b9622fd5a4193)

## 같은 원본을 다른 순서로 읽기

격자에서는 범위와 빈 영역을 먼저 비교합니다. 칸을 누르면 학습 묶음, 개념, 용어·기호 순서로 내려가고, 개념의 관계를 누르면 해당 개념의 전체 경로로 이동합니다.

화면 분류는 교과서 단원이나 최종 온톨로지 타입을 새로 정의하지 않습니다. 기존 개념 ID와 원본 r2를 그대로 참조하며, 원본 수정과 자동 동기화는 하지 않습니다.
